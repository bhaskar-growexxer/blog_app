## 1. Advanced Eloquent Relationships {#advanced-relationships}

### 1.1 Polymorphic Relationships - morphTo() and morphMany()

Polymorphic relationships allow a model to belong to multiple other models on a single association.

#### morphTo() - The Inverse Side

**Use Case**: When a model can belong to multiple different models.

```php
// Example: Comments can belong to Posts or Videos

// Migration
Schema::create('comments', function (Blueprint $table) {
    $table->id();
    $table->text('content');
    $table->morphs('commentable'); // Creates commentable_id and commentable_type
    $table->timestamps();
});

// Comment Model
class Comment extends Model
{
    public function commentable()
    {
        return $this->morphTo();
    }
}

// Usage
$comment = Comment::find(1);
$parent = $comment->commentable; // Returns Post or Video instance
```

#### morphMany() - The Parent Side

**Use Case**: When a model can have many of the same type of related model.

```php
// Post Model
class Post extends Model
{
    public function comments()
    {
        return $this->morphMany(Comment::class, 'commentable');
    }
}

// Video Model
class Video extends Model
{
    public function comments()
    {
        return $this->morphMany(Comment::class, 'commentable');
    }
}

// Usage
$post = Post::find(1);
$comments = $post->comments; // Get all comments for this post

// Creating comments
$post->comments()->create([
    'content' => 'Great post!'
]);
```

#### Additional Polymorphic Types

**morphOne()**: One-to-one polymorphic relationship
```php
class Post extends Model
{
    public function image()
    {
        return $this->morphOne(Image::class, 'imageable');
    }
}
```

**morphToMany()**: Many-to-many polymorphic relationship
```php
class Post extends Model
{
    public function tags()
    {
        return $this->morphToMany(Tag::class, 'taggable');
    }
}
```

### 1.2 Has Many Through Relationship

**Use Case**: Access distant relationships through intermediate models.

#### Basic Example: Countries → Users → Posts

```php
// Migration Setup
Schema::create('countries', function (Blueprint $table) {
    $table->id();
    $table->string('name');
});

Schema::create('users', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->foreignId('country_id')->constrained();
});

Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->foreignId('user_id')->constrained();
});

// Country Model
class Country extends Model
{
    public function posts()
    {
        return $this->hasManyThrough(
            Post::class,    // Final model
            User::class,    // Intermediate model
            'country_id',   // Foreign key on users table
            'user_id',      // Foreign key on posts table
            'id',           // Local key on countries table
            'id'            // Local key on users table
        );
    }
}

// Usage
$country = Country::find(1);
$posts = $country->posts; // All posts from users in this country
```

#### Advanced Example: Three Levels Deep

```php
// Suppliers → Countries → Users → Orders

class Supplier extends Model
{
    public function countries()
    {
        return $this->hasMany(Country::class);
    }
    
    // Access orders through countries and users
    public function orders()
    {
        return $this->hasManyThrough(
            Order::class,
            User::class,
            'country_id',  // Foreign key on users
            'user_id',     // Foreign key on orders
        )->through('countries');
    }
}
```

## 2. Query Performance Optimization {#query-optimization}

### 2.1 Understanding the N+1 Query Problem

**The Problem**:
```php
// BAD: N+1 queries (1 query for posts + N queries for authors)
$posts = Post::all(); // 1 query

foreach ($posts as $post) {
    echo $post->author->name; // N queries (one per post)
}
// Total: 1 + 100 = 101 queries for 100 posts
```

### 2.2 Eager Loading with with()

**Solution**: Load relationships upfront

```php
// GOOD: 2 queries total
$posts = Post::with('author')->get(); // 2 queries only

foreach ($posts as $post) {
    echo $post->author->name; // No additional queries
}
```

#### Multiple Relationships
```php
$posts = Post::with(['author', 'comments', 'tags'])->get();
```

#### Nested Relationships
```php
$posts = Post::with('comments.author')->get();
```

#### Conditional Eager Loading
```php
$posts = Post::with(['author', 'comments' => function ($query) {
    $query->where('approved', true)
          ->orderBy('created_at', 'desc')
          ->limit(5);
}])->get();
```

### 2.3 Lazy Eager Loading with load()

**Use Case**: Load relationships after model is already retrieved

```php
$posts = Post::all();

// Later in code, load relationships if needed
if ($needAuthors) {
    $posts->load('author');
}

// Load with constraints
$posts->load(['comments' => function ($query) {
    $query->recent();
}]);
```

### 2.4 Constrained Eager Loading

**Laravel 8.42+**: Apply relationship constraints without closures

```php
// Before
Post::with(['comments' => function ($query) {
    $query->where('approved', true);
}])->get();

// After: Using relationship methods
Post::with('approvedComments')->get();

// In Post Model
public function approvedComments()
{
    return $this->hasMany(Comment::class)->where('approved', true);
}
```

### 2.5 Counting Related Models with withCount()

**Use Case**: Get count of related models efficiently

```php
// Get posts with comment count
$posts = Post::withCount('comments')->get();

foreach ($posts as $post) {
    echo $post->comments_count; // No additional query
}

// Multiple counts
$posts = Post::withCount(['comments', 'likes', 'shares'])->get();

// Conditional counts
$posts = Post::withCount([
    'comments',
    'comments as approved_comments_count' => function ($query) {
        $query->where('approved', true);
    }
])->get();
```

#### Advanced withCount() Usage

```php
// Sum instead of count
$posts = Post::withSum('comments', 'likes_count')->get();
// Access: $post->comments_sum_likes_count

// Average
$posts = Post::withAvg('comments', 'rating')->get();
// Access: $post->comments_avg_rating

// Min/Max
$posts = Post::withMin('comments', 'created_at')->get();
$posts = Post::withMax('comments', 'created_at')->get();
```

## 3. Filtering Related Data {#filtering-data}

### 3.1 whereHas() - Filter by Relationship Existence

**Use Case**: Get models that have related models matching certain conditions

```php
// Get posts that have at least one approved comment
$posts = Post::whereHas('comments', function ($query) {
    $query->where('approved', true);
})->get();

// With minimum count
$posts = Post::whereHas('comments', function ($query) {
    $query->where('approved', true);
}, '>=', 3)->get(); // At least 3 approved comments

// Nested relationships
$countries = Country::whereHas('users.posts', function ($query) {
    $query->where('published', true);
})->get();
```

### 3.2 orWhereHas() - OR Conditions

```php
// Posts with approved comments OR more than 100 likes
$posts = Post::whereHas('comments', function ($query) {
    $query->where('approved', true);
})->orWhereHas('likes', function ($query) {
    $query->where('value', '>', 100);
})->get();
```

### 3.3 doesntHave() and whereDoesntHave()

```php
// Posts without any comments
$posts = Post::doesntHave('comments')->get();

// Posts without approved comments
$posts = Post::whereDoesntHave('comments', function ($query) {
    $query->where('approved', true);
})->get();
```

### 3.4 Relationship Constraints

```php
// In your model - define constrained relationships
class Post extends Model
{
    public function recentComments()
    {
        return $this->hasMany(Comment::class)
                    ->where('created_at', '>=', now()->subDays(7))
                    ->orderBy('created_at', 'desc');
    }
    
    public function topComments()
    {
        return $this->hasMany(Comment::class)
                    ->where('likes', '>', 10)
                    ->orderBy('likes', 'desc');
    }
}

// Usage
$posts = Post::with('recentComments')->get();
```

## 4. Query Scopes {#query-scopes}

### 4.1 Local Scopes

**Use Case**: Reusable query constraints

```php
// Post Model
class Post extends Model
{
    // Define scope with 'scope' prefix
    public function scopeActive($query)
    {
        return $query->where('status', 'active');
    }
    
    public function scopePublished($query)
    {
        return $query->where('published', true)
                     ->where('published_at', '<=', now());
    }
    
    public function scopePopular($query, $threshold = 100)
    {
        return $query->where('views', '>', $threshold);
    }
    
    public function scopeByAuthor($query, $authorId)
    {
        return $query->where('author_id', $authorId);
    }
}

// Usage - call without 'scope' prefix
$posts = Post::active()->get();
$posts = Post::published()->popular()->get();
$posts = Post::popular(500)->get(); // Custom threshold
$posts = Post::byAuthor(1)->published()->get();

// Chaining multiple scopes
$posts = Post::active()
            ->published()
            ->popular()
            ->orderBy('created_at', 'desc')
            ->paginate(10);
```

#### Dynamic Scopes

```php
public function scopeOfType($query, $type)
{
    return $query->where('type', $type);
}

public function scopeCreatedBetween($query, $startDate, $endDate)
{
    return $query->whereBetween('created_at', [$startDate, $endDate]);
}

// Usage
$posts = Post::ofType('article')
            ->createdBetween('2024-01-01', '2024-12-31')
            ->get();
```

### 4.2 Global Scopes

**Use Case**: Automatically apply constraints to all queries

#### Anonymous Global Scopes

```php
class Post extends Model
{
    protected static function booted()
    {
        static::addGlobalScope('active', function (Builder $query) {
            $query->where('status', 'active');
        });
    }
}

// All queries automatically filtered
$posts = Post::all(); // Only active posts
$post = Post::find(1); // Only if active

// Remove global scope when needed
$posts = Post::withoutGlobalScope('active')->get();
$posts = Post::withoutGlobalScopes()->get(); // Remove all
```

#### Class-Based Global Scopes

```php
// Create scope class
namespace App\Scopes;

use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Scope;

class ActiveScope implements Scope
{
    public function apply(Builder $builder, Model $model)
    {
        $builder->where('status', 'active');
    }
}

// Apply to model
use App\Scopes\ActiveScope;

class Post extends Model
{
    protected static function booted()
    {
        static::addGlobalScope(new ActiveScope);
    }
}
```

#### Practical Global Scope Example: Soft Deletes

```php
class TenantScope implements Scope
{
    public function apply(Builder $builder, Model $model)
    {
        if (auth()->check()) {
            $builder->where('tenant_id', auth()->user()->tenant_id);
        }
    }
}

// Now all queries automatically filter by tenant
class Post extends Model
{
    protected static function booted()
    {
        static::addGlobalScope(new TenantScope);
    }
}
```

## 5. Best Practices {#best-practices}

### 5.1 Relationship Definition Best Practices

```php
class Post extends Model
{
    // ✅ GOOD: Clear, specific relationship names
    public function publishedComments()
    {
        return $this->hasMany(Comment::class)->where('status', 'published');
    }
    
    // ✅ GOOD: Use constants for values
    const STATUS_PUBLISHED = 'published';
    
    public function publishedComments()
    {
        return $this->hasMany(Comment::class)
                    ->where('status', self::STATUS_PUBLISHED);
    }
    
    // ❌ BAD: Generic names with filters in query
    public function comments()
    {
        return $this->hasMany(Comment::class);
    }
    // Then filtering in controller: $post->comments()->where(...)
}
```

### 5.2 Eager Loading Best Practices

```php
// ✅ GOOD: Load exactly what you need
$posts = Post::with(['author:id,name', 'category:id,name'])->get();

// ✅ GOOD: Use relationship methods for consistency
$posts = Post::with('approvedComments')->get();

// ❌ BAD: Loading too much
$posts = Post::with('author')->get(); // Loads all author columns

// ✅ GOOD: Conditional loading
if ($request->has('include_comments')) {
    $posts->load('comments');
}
```

### 5.3 Query Optimization Checklist

1. **Always use eager loading** when accessing relationships in loops
2. **Use withCount()** instead of loading full relationships when you only need counts
3. **Select only needed columns** to reduce memory usage
4. **Use chunk()** for large datasets
5. **Cache frequent queries** using Laravel Cache

```php
// ✅ Optimized query example
$posts = Cache::remember('featured-posts', 3600, function () {
    return Post::with(['author:id,name', 'category:id,name'])
               ->withCount('comments')
               ->select('id', 'title', 'author_id', 'category_id', 'published_at')
               ->published()
               ->popular()
               ->orderBy('published_at', 'desc')
               ->limit(10)
               ->get();
});
```

### 5.4 Avoiding Common Pitfalls

```php
// ❌ BAD: N+1 in relationships
class Post extends Model
{
    public function getAuthorNameAttribute()
    {
        return $this->author->name; // Causes N+1 if author not loaded
    }
}

// ✅ GOOD: Protected accessor with loaded check
class Post extends Model
{
    protected $with = ['author']; // Auto-eager load
    
    public function getAuthorNameAttribute()
    {
        return $this->author->name;
    }
}

// ❌ BAD: Counting in loop
foreach ($posts as $post) {
    $commentCount = $post->comments()->count(); // N queries
}

// ✅ GOOD: Use withCount
$posts = Post::withCount('comments')->get();
foreach ($posts as $post) {
    $commentCount = $post->comments_count; // No queries
}
```

## 6. Practical Examples {#practical-examples}

### Example 1: Blog System with Advanced Relationships

```php
// Models Setup
class User extends Model
{
    public function posts()
    {
        return $this->hasMany(Post::class);
    }
    
    public function comments()
    {
        return $this->hasMany(Comment::class);
    }
    
    public function scopeActive($query)
    {
        return $query->where('is_active', true);
    }
}

class Post extends Model
{
    public function author()
    {
        return $this->belongsTo(User::class, 'user_id');
    }
    
    public function comments()
    {
        return $this->morphMany(Comment::class, 'commentable');
    }
    
    public function tags()
    {
        return $this->morphToMany(Tag::class, 'taggable');
    }
    
    public function scopePublished($query)
    {
        return $query->where('status', 'published')
                     ->where('published_at', '<=', now());
    }
    
    public function scopeWithActiveComments($query)
    {
        return $query->withCount(['comments' => function ($q) {
            $q->where('approved', true);
        }]);
    }
}

class Comment extends Model
{
    public function commentable()
    {
        return $this->morphTo();
    }
    
    public function author()
    {
        return $this->belongsTo(User::class, 'user_id');
    }
    
    public function scopeApproved($query)
    {
        return $query->where('approved', true);
    }
}

// Controller Usage
class PostController extends Controller
{
    public function index()
    {
        $posts = Post::with([
                'author:id,name,avatar',
                'tags:id,name',
                'comments' => function ($query) {
                    $query->approved()
                          ->with('author:id,name')
                          ->latest()
                          ->limit(5);
                }
            ])
            ->withCount('comments')
            ->published()
            ->whereHas('author', function ($query) {
                $query->active();
            })
            ->orderBy('published_at', 'desc')
            ->paginate(20);
            
        return view('posts.index', compact('posts'));
    }
    
    public function popularPosts()
    {
        return Post::withCount(['comments', 'likes'])
                   ->having('comments_count', '>', 10)
                   ->orHaving('likes_count', '>', 100)
                   ->published()
                   ->orderByDesc('comments_count')
                   ->get();
    }
}
```

### Example 2: E-commerce System

```php
class Country extends Model
{
    public function users()
    {
        return $this->hasMany(User::class);
    }
    
    // Get all orders from users in this country
    public function orders()
    {
        return $this->hasManyThrough(Order::class, User::class);
    }
    
    // Get total revenue
    public function getTotalRevenueAttribute()
    {
        return $this->orders()->sum('total_amount');
    }
}

class Order extends Model
{
    public function user()
    {
        return $this->belongsTo(User::class);
    }
    
    public function items()
    {
        return $this->hasMany(OrderItem::class);
    }
    
    public function scopePending($query)
    {
        return $query->where('status', 'pending');
    }
    
    public function scopeCompleted($query)
    {
        return $query->where('status', 'completed');
    }
}

// Analytics Controller
class AnalyticsController extends Controller
{
    public function countryStats($countryId)
    {
        $country = Country::with(['users' => function ($query) {
                $query->withCount(['orders' => function ($q) {
                    $q->completed();
                }]);
            }])
            ->withCount('orders')
            ->find($countryId);
            
        $topUsers = $country->users()
            ->withSum('orders', 'total_amount')
            ->orderByDesc('orders_sum_total_amount')
            ->limit(10)
            ->get();
            
        return view('analytics.country', compact('country', 'topUsers'));
    }
}
```

### Example 3: Multi-Tenant Application

```php
// Global Scope for Tenant Isolation
class TenantScope implements Scope
{
    public function apply(Builder $builder, Model $model)
    {
        if (auth()->check() && auth()->user()->tenant_id) {
            $builder->where('tenant_id', auth()->user()->tenant_id);
        }
    }
}

// Base Model for Tenant-Scoped Models
abstract class TenantModel extends Model
{
    protected static function booted()
    {
        static::addGlobalScope(new TenantScope);
        
        static::creating(function ($model) {
            if (auth()->check() && !$model->tenant_id) {
                $model->tenant_id = auth()->user()->tenant_id;
            }
        });
    }
}

// Usage
class Project extends TenantModel
{
    public function tasks()
    {
        return $this->hasMany(Task::class);
    }
    
    public function scopeActive($query)
    {
        return $query->where('status', 'active');
    }
}

// All queries automatically filtered by tenant
$projects = Project::with('tasks')->active()->get();
```

## Summary

This guide covered:

1. **Advanced Relationships**: morphTo(), morphMany(), hasManyThrough() for complex data models
2. **Performance Optimization**: with(), load(), constrained eager loading, withCount() to eliminate N+1 queries
3. **Data Filtering**: whereHas(), orWhereHas(), relationship constraints for precise queries
4. **Query Scopes**: Local scopes (scopeActive()) and global scopes for reusable, clean queries
5. **Best Practices**: Building scalable Laravel applications with optimized Eloquent ORM patterns

### Key Takeaways

- Always eager load relationships accessed in loops
- Use scopes for reusable query logic
- Choose the right relationship type for your data model
- Optimize queries with withCount() when you don't need full relationships
- Apply global scopes for cross-cutting concerns like multi-tenancy
- Profile your queries in development to catch N+1 issues early
